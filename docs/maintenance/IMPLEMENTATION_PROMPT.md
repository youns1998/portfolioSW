# 편집 기준

- 세 주력 저장소: portfolioSPR, portfolioGIS, cad-productivity-palette.
- 프로젝트 코드는 각 저장소에서 수정하고 SoftwarePortfolio.code-workspace로 함께 엽니다.
- 소개 페이지는 간단한 텍스트 목록과 GitHub 직접 링크를 유지합니다.
- 설명은 현재 구현·검증 결과와 일치시킵니다. 확인하지 않은 결과를 완료로 쓰지 않습니다.
- 자기소개·학력·자격·연락처, Organizer·건축 도면·BIM은 SW 페이지에 추가하지 않습니다.
- README는 기능·실행·코드 위치·검증 범위를 짧고 정확하게 씁니다. 상세 설명은 docs/에 둡니다.
- 정적 페이지는 main /docs로 배포합니다.
